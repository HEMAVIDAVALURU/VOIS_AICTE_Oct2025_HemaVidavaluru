# **Airbnb Hotel Booking Analysis**
## **📌 Project Overview**

The Airbnb Hotel Booking Analysis project examines booking patterns, customer behavior, pricing trends, and availability using real-world Airbnb dataset features. This analysis helps identify booking demand, cancellation patterns, seasonal trends, and factors influencing customer choices.

## **🔍 Key Objectives**

Analyze booking status (confirmed, canceled, etc.)

Study guest demographics and preferences

Understand price variations across room types and locations

Identify seasonal trends and peak booking periods

Explore factors affecting stay duration and cancellations

## **📊 Key Insights**

Room type vs. price distribution

Location-based price and demand patterns

Booking vs. cancellation trends

Monthly/seasonal booking behavior

Correlation between stay duration and booking lead time
